# Lottie Canto "Colour Palette" kalimba

A 17-key C-major kalimba built into a guitar-pedal-style aluminum enclosure,
with a contact mic and onboard effects. Made by UK builder Lottie Canto.
(Identified from Sam's description "kalimba called the color palette" —
confirm it matches.)

## Controls and I/O

- **Mode** — picks one of 8 reverb/delay effects
- **Adjust** — the effect's parameter (e.g. delay time / reverb size)
- **Mix** — wet/dry
- Output: 1/4in mono. Power: 9V DC center-negative pedal supply
  (third-party sourced — check the label on the unit).

No firmware.

## Tuning layout (standard 17-key C major)

The **center (longest) tine is the lowest C**; notes climb the C major scale
alternating left/right as you move outward. Range is C4 → E6 (some makers
label it an octave higher). Typical layout, left → right:

```
D6 B5 G5 E5 C5 A4 F4 D4 [C4] E4 G4 B4 D5 F5 A5 C6 E6
```

Confirm against the engravings on Sam's unit and correct this if it differs.
Kalimba tabs number the notes 1–7 (C D E F G A B) with dots for octaves:
`1` = center C, `1°` = next C up.

Tuning: tap the tine with a small hammer — push it **in** (shorter) to raise
pitch, **out** (longer) to lower. Small taps; check with the BOSS tuner in
chromatic mode.
