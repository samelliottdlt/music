# Fender Bass VI

Six-string bass tuned like a guitar **one octave lower**:
E1 A1 D2 G2 B2 E3. Covers bass and baritone-guitar range. Variant **TODO**
(e.g. Squier Classic Vibe Bass VI, Fender American Vintage II 1962 Bass VI).

## Controls (typical)

- 3 single-coil pickups, each with its own on/off slide switch → 7 combos.
- Squier Classic Vibe adds a "strangle" (bass-cut) switch.
- Master volume + tone. Jaguar-style floating vibrato bridge.

Fender's site sometimes blocks automated fetches; confirm exact specs
(e.g. string gauges) on the live page for the specific variant.

## Using it with the rig

- Guitar patterns (chords, riffs) sound deep and baritone; single notes on
  the low strings work as basslines.
- It covers bass frequencies — guitar-voiced drives can thin out the low end.
  On the Chroma Console, compare Character effects with the bass strings.
- Tuner: use chromatic mode and tune one octave below guitar.
