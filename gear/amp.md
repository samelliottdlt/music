## Getting the amp into the TX-6 safely

| Amp output | OK into TX-6? | Notes |
|------------|---------------|-------|
| Line out | Yes | Best option. 1/4in → 3.5mm cable |
| Headphone out | Usually | Often includes cab simulation; hotter — start with low TX-6 gain |
| DI / speaker-emulated out | Yes | Use line level if switchable; XLR needs an adapter/DI |
| **Speaker out** | **Never directly** | Power-amp level — will damage the TX-6 input. Needs a load box with a line/DI out |

Also: never run a tube amp's speaker output with **nothing** connected
(no speaker and no load box) — it can damage the output transformer.
