# Teenage Engineering OB-4

Portable "magic radio" speaker. Used as the monitor for the TX-6 mix.
(TE has no "OB-6" — this is the OB-4.)

## Official docs

- User guide: https://teenage.engineering/guides/ob-4
- Product/spec page: https://teenage.engineering/products/ob-4
- Companion app: **orthoplay** (iOS / Android)

## Firmware update

The OB-4 has **no USB update**. Update it through the **orthoplay** app:
pair the OB-4, open its settings in orthoplay — it shows the installed
software version and an update button when one is available.

## Inputs / outputs

| Input | Details |
|-------|---------|
| Line in | 3.5mm stereo on the back. Use a **3-pole** (TRS) cable, not 2- or 4-pole. Red blinking LED = clipping |
| Bluetooth | Classic (AAC) audio; BLE for volume/remote. Simple mode (1 device) or party mode (2) via orthoplay; optional auto-switch |
| FM radio | Antenna in the handle. Can receive the **OP-1 field's FM transmitter** |
| Disk mode | On-board functions (ambient, loop, metronome, noise…), not storage |

No outputs. Power: AC mains inlet (100–240 V), internal battery
(~8 h Bluetooth at high volume, ~72 h FM).

Cycle inputs with the **input** button.

## Magic functions (hold input as shift)

- Continuously records the last ~2 hours to a virtual "magic tape" — scrub/
  rewind by holding input + turning volume.
- **Loop:** capture a loop from what's playing (beat-matched); adjust length/
  speed.
- **Ambient:** turn any source into a generative soundscape.
- Noise generator (white/pink/brown, sleep timer), 808-style metronome.

Creative idea fuel: loop or ambient-ify the TX-6 mix right on the speaker.
